## 🎯 What We're Building

**Inner Compass** is an AI-powered mental wellness platform that helps users track their mental health, find nearby resources, and connect with supportive communities - all while keeping their privacy protected.

### ✨ Key Features
- 📝 **Smart Mood Tracking** - AI analyzes your journal entries for emotional patterns
- 🗺️ **Find Help Nearby** - Locate mental health resources within your area
- 🤖 **24/7 AI Support** - Chat with our AI assistant anytime
- 💬 **Anonymous Community** - Connect with others safely and privately
- 📊 **Progress Dashboard** - Visualize your mental health journey

---

## 🛠️ Tech Stack

**Frontend:** React, Tailwind CSS, Redux  
**Backend:** Node.js, Express, MongoDB  
**AI/ML:** TensorFlow, OpenAI GPT, Dialogflow  
**Maps:** Google Maps API  
**Security:** JWT, HIPAA Compliance

## 🚀 Quick Start

```bash
# Clone the repo
git clone https://github.com/techcrusaders/inner-compass.git
cd inner-compass

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env
# Add your API keys

# Start the app
npm run dev
```

### Environment Variables
```env
OPENAI_API_KEY=your_openai_key
GOOGLE_MAPS_API_KEY=your_maps_key
MONGODB_URI=your_mongodb_connection
JWT_SECRET=your_jwt_secret
```
