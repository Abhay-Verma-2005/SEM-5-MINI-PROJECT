# 🌍 Mood Connect App

> A Real-Time Social Connect App via Smart Map with ML Feature  
> **Team – Tech Crusaders**

---

## 📌 Synopsis
In today’s digital age, loneliness and disconnection are growing issues. While existing social platforms focus on global entertainment and distant ties, **Mood Connect App** helps people form **real-time, local companionship** by connecting with nearby users through shared activities, moods, and interests.  

---

## 🚀 Problem Statement
To ease loneliness and foster real connections, our app helps people connect with **nearby users** through shared activities and interests—something current social platforms often miss.

---

## 📝 Problem Description
Despite multiple social apps, users struggle to find **meaningful nearby connections**. Current platforms:
- Focus on entertainment & global reach.
- Fail to support **real-time, local interactions**.  

👉 **Mood Connect** provides:
- A **secure & interactive platform**.
- **Mood-based connections**.
- **Trustworthy & private interactions**.

---

## 🎯 Project Objectives
- Enable users to connect with others within a **1 km radius**.
- Integrate **Machine Learning (ML)** for:
  - ✅ **Friend Recommendation System**  
  - ✅ **Woohu! Mood Note** (personalized map note generated by activity)
- Ensure **anonymous profiles** & **obfuscated locations**.
- Collect **post-meeting feedback** for trust-building.

---

## 📌 Scope
- 🗺️ Map-based interface (1 km radius).  
- 📝 Activity notes & interactive story sharing.  
- 🤖 Smart ML-powered recommendations.  
- 🔐 Secure & private chat system.  

---

## ⚙️ Methodology (Process Flow)

### 1️⃣ Data Gathering
- Collect activities, moods, personal notes, and stories.

### 2️⃣ Preprocessing
- Clean data → extract features (TF-IDF, embeddings).

### 3️⃣ Model Training & Selection
- **Friend Recommendation** → Hybrid (Collaborative + Content-based).  
- **Mood Note** → Suggests friends & generates map notes using activity history.

### 4️⃣ User Interface Integration
- Interactive map with **real-time notes**.  
- Story posting (text/media).  
- Secure chat requests.
